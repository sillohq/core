# Not published

These pages document `sillo-contrib`, a package that does not exist yet: it is
not on PyPI, and `github.com/sillohq/sillo-contrib` is a 404. The repository
they link to publishes `nexios_contrib`, from the framework this one was renamed
from — the rename was never finished.

Every page here tells a reader to `uv add sillo-contrib` and
`from sillo_contrib... import ...`, neither of which can work. They were moved
out of `src/content/docs` so the docs site stops publishing instructions that
fail, and kept here rather than deleted so they can go back when the package
exists.

To restore: move this directory back to `src/content/docs/community` and add it
to the sidebar in `astro.config.mjs`.
