# Sillo v1 — the context-handler rewrite

Branch: `v1`. **No backward compatibility.** The old `(request, response)` handler
signature, the `Request` class, and the request-scoped `Response` / `Responder`
manager are being removed, not deprecated.

## Target shape

```python
from sillo import SilloApp, HttpContext, json, Depend, Query

app = SilloApp()

@app.get("/users/{id:int}")
def show(ctx: HttpContext, id: int):
    return json({"id": id})                  # or ctx.params["id"]

@app.get("/search")
async def search(ctx: HttpContext, db=Depend(get_db), q=Query("")):
    return json(await db.find(q))

@app.websocket("/room/{name}")
async def room(ctx: WebSocketContext, name: str):
    await ctx.accept()
    await ctx.send_json({"room": name})
```

Middleware is `(ctx, call_next)` and ends the chain by returning a response
instead of awaiting `call_next`:

```python
class RequireLogin:
    async def __call__(self, ctx, call_next):
        if ctx.user is None:
            return redirect("/login")        # short-circuit
        return await call_next()
```

## Class hierarchy (`sillo/core/http/context.py` — DONE)

```
BaseContext(_MergedParams, HTTPConnection)     # shared connection surface + ctx.params
HttpContext(_MergedParams, Request-body)       # HTTP request; the handler argument
WebSocketContext(_MergedParams, WebSocket-body)# WS connection; the handler argument
```

`ctx.params` = path params merged over query params (path wins); `ctx.path_params`
and `ctx.query_params` stay for the unmerged views.

`json / html / text / redirect / file / stream` — free response builders in
`sillo/core/http/shortcuts.py` (DONE), returning bare `BaseResponse` subclasses.
No `Responder` involved.

## Remaining (each is its own commit)

### 1. Rename the internal classes, drop the old public names
- `sillo/core/http/request.py`: `HTTPConnection` → `BaseContext` body, `Request`
  → `HttpContext` body. Collapse `context.py` into being the definition site (no
  subclass indirection). Delete `Request`, `ClientDisconnect` stays.
- `sillo/websockets/base.py`: `WebSocket` → `WebSocketContext` (keep
  `WebSocketDisconnect`, `WebSocketState`).
- `sillo/core/http/__init__.py`, `sillo/__init__.py`, `sillo/types.py`: drop
  `Request`, drop the `Responder as Response` re-export from the public surface
  (keep `Responder` internal only where the router still needs it until step 3).
- ~40 `from sillo.core.http import Request` / `from sillo.types import Request`
  sites: rewrite to `HttpContext`. Word-boundary only — do **not** touch
  `RequestValidationError`, `RequestContext`, `RequestId*`.

### 2. Middleware: `(ctx, call_next)` (`sillo/middleware/base.py`)
- Rewrite `BaseMiddleware.__call__` to `(self, ctx, call_next)`. Returning a
  `BaseResponse` short-circuits; returning `None` / awaiting `call_next()`
  continues. Drop `process_request` / `process_response` two-arg hooks — a single
  `async def dispatch(self, ctx, call_next)` override.
- Rewrite the 12 subclasses: `security/{cors,csrf,ratelimit,shield}`,
  `auth/middleware.py`, `session/middleware.py`, `templating/middleware.py`,
  `normalize/middleware.py`, `http/{accepts,etag}.py`,
  `http/lifecycle/middleware.py`.
- `sillo/_internals/_middleware.py` (`BaseHTTPMiddleware`, `_CachedRequest`):
  re-cast around `HttpContext`; `RequestResponseEndpoint` becomes
  `Callable[[HttpContext], Awaitable[BaseResponse]]`.
- The raw-ASGI middleware (`middleware/gzip.py`, security `_middleware.py` ASGI
  paths) are unaffected — they operate on `(scope, receive, send)`.

### 3. Router dispatch (`sillo/core/routing/router.py`)
- `_route_asgi_app` (~L369): build one `HttpContext(scope, receive, send)`; drop
  `Response(request)`.
- `get_route_handler` (~L607) / the call at ~L675: `handler(ctx, **path_params,
  **injected)` — single leading arg, no `(request, response)` branch, no
  `is_async_callable` per request (hoist to `Route.__init__`).
- `_find_body_param` / `_third_param_name`: index from `[1:]` (skip only `ctx`),
  not `[2:]`.
- `WebsocketRoute.handle` (`websocket.py` ~L226): build `WebSocketContext`; pass
  matched path params as kwargs (currently dropped at ~L201).
- Exception handlers (`exception_handler.py`, `core/error/handler.py`): signature
  `(ctx, exc)` instead of `(request, response, exc)`.

### 4. Subsystems that reach for `request` / `response`
`auth` backends & guards, `security/ratelimit`, `graphql/handler.py`,
`templating`, `static.py`, `handlers/not_found.py`, `normalize`, `http/*`
helpers. Each takes `ctx` now; response building goes through the shortcuts.

### 5. Tests
`core/tests/**` — every handler and middleware in the fixtures moves to the new
signature. `testclient` itself is transport-level and mostly unaffected; its
assertions about `response.json()` etc. are on the client side and stay.

### 6. Sibling packages (separate repos, separate branches)
`sillo-inertia` (`adapter.py._endpoint_signature` — delete the fake-signature
shim), `sillo-oauth`.
